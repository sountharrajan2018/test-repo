Angle encoding

A quantum model can only work on data that has been loaded into qubits. Angle encoding gives each feature its own qubit and uses the feature as a rotation angle. Move the sliders to see how the numbers become quantum states and measurement probabilities.

RY(θ)|0⟩ = cos(θ/2)|0⟩ + sin(θ/2)|1⟩

1. Data to angles

Raw features on a 0 to 6 scale are stretched onto angles from 0 to π, so θ = x / 6 · π. Going past π would rotate the qubit back towards |0⟩, and two different inputs could give the same state.

2. The circuit

One RY gate per qubit, then a measurement. The circuit is one gate deep, and the qubits never interact, so no entanglement is created.

3. Each qubit on its own

The circle is a slice through the Bloch sphere: |0⟩ at the top, |1⟩ at the bottom. The arrow is tipped by θ. The amplitudes use θ/2, so a full tip of π takes |0⟩ all the way to |1⟩.

4. Both qubits together

The joint state is the tensor product: every amplitude of qubit 1 multiplied by every amplitude of qubit 0. Outcomes use Qiskit's order, q1 q0, with qubit 0 on the right.

Points to watch

  • Bit order. Qiskit puts qubit 0 on the right of a bitstring. Textbooks such as Nielsen & Chuang put it on the left, so their tables swap 01 and 10.
  • Amplitudes are not probabilities. A probability is the amplitude squared. Amplitudes can cancel each other when later gates act on them; probabilities cannot.
  • Cost. One qubit per feature. Amplitude encoding fits 2ⁿ features into n qubits but needs a much deeper circuit.
  • Check it in Python. python angle_encoding.py builds the same circuit in Qiskit. At the example values (2, 3) it prints probabilities 0.375 / 0.125 / 0.375 / 0.125, matching this page.
